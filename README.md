## Featured projects

### [CTPS · Gaming club operations](https://github.com/khurik662/ctps-showcase)

A local prototype for managing play sessions, checkout, and inventory. The public case study walks through the cashier and owner workflows and records the results of a clean demo run on Apple silicon.

### [Cars](https://github.com/khurik662/cars)

An Angular car-rental demo with a filterable catalog and a booking enquiry form. The repository includes the compiled site and a guide to running it locally.

### [EmoDet](https://github.com/khurik662/EmoDet_cl#readme)

A Python computer vision demo for exploring facial expression labels from webcam frames. It shares a DeepFace detector between a Flask browser interface and an OpenCV desktop interface.
